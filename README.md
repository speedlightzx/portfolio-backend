# Portfólio Backend

## 📌 Sobre o projeto:
Esse é o backend do meu portfólio que me permite mexer nos dados serão exibidos no frontend.

## 🔧 Tecnologias usadas no projeto:
- Framework: Nest.js
- Linguagem: Typescript
- ORM: Drizzle
- Supabase
- Docker

## ❓ Por que essas tecnologias?
Meu objetivo era construir um backend simples, robusto e rápido, então optei pelo Drizzle por ser um ORM rápido e parecido com SQL e Nest.js pela sua robustez.
